# GameEngineMidterm

 The intended function of my factory class is to be able to spawn both the enemies and then the food items after they die. 
 If I were able to implement this factory as I wanted it I would have also been able to create it as a singleton as I could filter all the enemy and fruit generation through a single factory that way.

 I also attempted to create a more basic singleton implementation that, given more time, would have handled the scene transfers, win/lose conditions, and score tracking.
